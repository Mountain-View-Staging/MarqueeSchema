# Inter 4.1: the test brand's typeface

The official release of Inter, taken from its project unmodified.

- **Release:** v4.1, published 2024-11-16: https://github.com/rsms/inter/releases/tag/v4.1
- **Asset:** `Inter-4.1.zip`, 33,707,794 bytes, SHA-256
  `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`, downloaded 2026-09-27.
- **Licence:** SIL Open Font License 1.1 with no Reserved Font Name. `LICENSE.txt` is the
  release's own, verbatim, and must travel with every copy of these files.
- **Approved** for the public test shows by the operator on 2026-09-27 (plan D-r2-28).

Six faces, chosen to exercise the branding specification's face table: a weight with no italic
(SemiBold), and a display face used by name (InterDisplay-Black).

- `apple/` holds the release's `extras/otf/<face>.otf`, the source files.
- `web/` holds the release's own `web/<face>.woff2` builds, not conversions made here.
